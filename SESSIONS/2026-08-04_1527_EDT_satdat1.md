## P2 · 2026-08-04 15:49 EDT · "How can you be one behind GitHub if you just cloned?"

**Answered: it cannot be, and it never was.** The clone was exactly current — local
`main` one ahead (the restructure commit), zero behind. The ahead/behind figure was
branch-vs-branch and its direction had been reversed: `origin/uri` was **1 ahead of
`main` and 3 behind**, not 3 and 1.

**The mechanism, because it is invisible.** `git rev-list --left-right --count A...B`
prints *A-not-B* on the left and *B-not-A* on the right. It was run as
`origin/main...origin/uri`, returned `3  1`, and the left count was read as `uri`'s.
**Both numbers are real**, so the output gives no signal that it has been misread —
only a second command disagrees with it.

Corrected in `STATUS.md`, `TASKS.md` #1, and the P1 entry of the source log. Both
commit messages were amended, which is why the source log names `82e362d` where the
commit is now `a55f97b`.
